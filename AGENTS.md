# Правила для ИИ-агентов в этом репозитории

Файл читает любой ИИ-ассистент (Claude Code, Codex и др.) перед тем, как менять код. Здесь инварианты, которые нельзя ломать, и то, как проверять работу.

## Что это

Концепт личного кабинета студента для конкурса MGIMO×AI Challenge 2026. Пять разделов: профиль, расписание, успеваемость, заявки, уведомления. Плюс кабинет сотрудника деканата.
FastAPI + Jinja2 (страницы рендерит сервер) + SQLAlchemy (проверенная конфигурация — SQLite).

```
app/main.py        маршруты, зависимости доступа, обработчики ошибок, заголовки безопасности
app/security.py    пароли (bcrypt), сессии, CSRF, ограничение попыток входа
app/services.py    расписание, успеваемость, дедлайны, справочник заявок — логика без HTTP
app/models.py      таблицы
app/seed.py        вымышленные демо-данные; даты считаются от сегодняшнего дня
app/templates/     страницы; общие куски — macros.html, каркас — base.html
app/static/        style.css (mobile-first), app.js (без фреймворков), logo.svg
tests/test_app.py  сквозные тесты
```

## Инварианты — не ломать

1. **Доступ проверяет сервер.** Каждый маршрут с личными данными берёт пользователя из зависимости `student` или `staff`. Записи ищутся с фильтром по `user.id` (см. `own_request`). На чужую запись ответ **404**, а не 403: не подтверждаем, что запись существует.
2. **Каждая POST-форма** (кроме входа, его защищает проверка `Origin` в middleware) содержит `<input type="hidden" name="csrf" value="{{ csrf }}">`, а обработчик вызывает `sec.check_csrf`.
3. **Никаких секретов в репозитории.** Пароли демо-аккаунтов хранятся только как bcrypt-хеши в `seed.py` или переменных `DEMO_HASH_*`. Открытые пароли — только в `*.local.md`, такие файлы в `.gitignore`.
4. **CSP строгая**: никаких inline-скриптов, `style="…"` и обработчиков `onclick`. Поведение — в `app.js` через `data-*` атрибуты. Ширина полос — классами `w-0…w-100` (функция `width_class` в `services.py`).
5. **Только вымышленные данные.** Никаких реальных ФИО, оценок, логинов, логотипа вуза. На каждой странице видна полоса «Концепт… не официальный сервис».
6. **Телефон от 360 px — основной экран.** После правок вёрстки проверить, что `document.documentElement.scrollWidth` не больше 360 на всех страницах.
7. **Лицензии**: только MIT, BSD, Apache, OFL и подобные. Иконки рисуем сами в `macros.html`. Шрифт Open Sans лежит в `app/static/fonts` (OFL), внешних CDN нет: CSP разрешает только свои файлы.

## Подводные камни (на них ИИ уже ошибался)

- **Не называть ключи словарей для шаблонов `items`, `keys`, `values`, `get`, `update`.** В Jinja `obj.items` вернёт метод словаря, а не значение. Поэтому список контрольных точек называется `kts`.
- **Связанные объекты пользователя** (группа → направление → факультет) загружаются сразу (`lazy="joined"`), потому что `base.html` использует их и на страницах ошибок, когда сессия базы уже закрыта.
- **Порядок правил в CSS важен**: слой для компьютера стоит в конце `style.css`, иначе базовые правила ниже по файлу его перебивают. Тёмная тема включается атрибутом `data-theme="dark"` (cookie `theme`), а не настройкой системы.
- **Тексты на русском**: падежи при подстановке названий (лучше брать в «кавычки» после двоеточия), дробные числа с запятой (фильтр `decimal`), без `text-transform: capitalize` — он делает заглавными все слова.
- **В воскресенье** расписание по умолчанию открывает следующую календарную неделю (`default_week`). Главная и расписание должны говорить об одной и той же неделе.

## Как проверять

```powershell
python -m pytest -q
python -m uvicorn app.main:app --port 8000
```

Тесты используют временную базу и свои пароли. Новые маршруты с личными данными добавлять вместе с тестом «чужой студент получает 404».
